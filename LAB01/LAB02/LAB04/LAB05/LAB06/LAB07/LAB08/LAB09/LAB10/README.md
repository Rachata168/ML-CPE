# ML Lab 10: Object Detection II --- YOLO

## 1. รายละเอียดโครงงาน

โครงงานนี้เป็นการทดลองตรวจจับวัตถุ (Object Detection) ด้วยโมเดล YOLO จากไลบรารี
Ultralytics โดยทดลองฝึกโมเดล เปรียบเทียบจำนวน Epoch และการตั้งค่าบางส่วน
รวมถึงทดสอบตรวจจับวัตถุจากภาพนิ่งและวิดีโอ

## 2. เครื่องมือที่ใช้

-   Python
-   Visual Studio Code (VS Code)
-   Ultralytics YOLO
-   ชุดข้อมูล `coco128.yaml`
-   โมเดลเริ่มต้น `yolo11n.pt`

## 3. การติดตั้ง

เปิด Terminal ใน VS Code ที่โฟลเดอร์โปรเจกต์ แล้วติดตั้งไลบรารีด้วยคำสั่ง:

``` bash
python -m pip install ultralytics
```

หากเครื่องมี Python หลายเวอร์ชัน ให้เลือก Interpreter ตัวเดียวกับที่ใช้ติดตั้ง
`ultralytics` ใน VS Code

## 4. ไฟล์หลักในโปรเจกต์

-   `train_model.py` --- ฝึกโมเดล YOLO
-   `compare_epochs.py` --- ทดลองเปรียบเทียบการฝึก 5, 10 และ 20 Epoch
-   `compare_settings.py` --- เปรียบเทียบการตั้งค่า Image Size และ Batch Size
-   `detect_image.py` --- ตรวจจับวัตถุจากภาพนิ่ง
-   `detect_video.py` --- ตรวจจับวัตถุจากไฟล์วิดีโอในโฟลเดอร์ `test_videos`
-   `evaluate_model.py` --- ประเมินผลโมเดล
-   `comparison_results/` --- เก็บไฟล์ผลการเปรียบเทียบ เช่น CSV
-   `runs/` --- เก็บโมเดลที่ฝึกแล้ว ผลการประเมิน และภาพกราฟ

## 5. วิธีใช้งาน

### ฝึกโมเดล

``` bash
python train_model.py
```

### เปรียบเทียบจำนวน Epoch

``` bash
python compare_epochs.py
```

### เปรียบเทียบการตั้งค่า

``` bash
python compare_settings.py
```

### ตรวจจับวัตถุจากภาพ

นำไฟล์ภาพที่ต้องการทดสอบใส่ในโฟลเดอร์ `test_images` จากนั้นรัน:

``` bash
python detect_image.py
```

### ตรวจจับวัตถุจากวิดีโอ

สร้างโฟลเดอร์ `test_videos` ภายในโฟลเดอร์โปรเจกต์ แล้วใส่ไฟล์วิดีโอ `.mp4`,
`.avi` หรือ `.mov` จากนั้นรัน:

``` bash
python detect_video.py
```

ไฟล์ผลลัพธ์ที่ได้จะถูกบันทึกไว้ในโฟลเดอร์ผลลัพธ์ของ Ultralytics ภายใต้ `runs/detect/`

### ประเมินผลโมเดล

``` bash
python evaluate_model.py
```

## 6. ผลการทดลอง

### เปรียบเทียบจำนวน Epoch

ผลที่บันทึกไว้จากการทดลอง:

    Epoch   Precision   Recall    mAP50   mAP50-95
  ------- ----------- -------- -------- ----------
        5      0.7139   0.6191   0.6993     0.5245
       10      0.7119   0.6599   0.7225     0.5451
       20      0.7978   0.6941   0.7616     0.5908

จากผลการทดลองนี้ การฝึก 20 Epoch ให้ค่า Recall, mAP50 และ mAP50-95
สูงที่สุดในสามการทดลองนี้

### เปรียบเทียบ Image Size และ Batch Size

  ------------------------------------------------------------------------------
  การตั้งค่า     Image Size Batch Size   Precision     Recall      mAP50   mAP50-95
  ----------- ---------- ---------- ----------- ---------- ---------- ----------
  imgsz_416          416          8      0.6555     0.6045     0.6423     0.4738

  imgsz_640          640          8      0.7140     0.6191     0.6993     0.5245

  batch_16           640         16      0.7709     0.6161     0.7166     0.5331
  ------------------------------------------------------------------------------

ผลการทดลองเบื้องต้นแสดงว่า Image Size 640 ให้ผลดีกว่า 416 เมื่อใช้ Batch Size 8
ส่วนการใช้ Batch Size 16 ให้ Precision และ mAP สูงกว่าในการทดลองนี้ แต่ Recall
ต่ำกว่าเล็กน้อย ทั้งนี้การทดลองแต่ละแบบใช้เพียง 5 Epoch จึงควรตีความเป็นผลเบื้องต้น
