## 1. ที่มาและวัตถุประสงค์

งานชิ้นนี้เป็นส่วนหนึ่งของใบงานที่ 3 เรื่อง Regression & Classification โดยเลือกทำ LAB 1 ซึ่งเป็นเรื่อง Regression ตามวัตถุประสงค์ของใบงานที่ให้เข้าใจหลักการของ Regression ในฐานะเทคนิคพื้นฐานของ Supervised Learning และสามารถอธิบายความแตกต่างระหว่างการทำนายค่าต่อเนื่อง (Continuous Value) ได้

โจทย์ที่เลือกใช้ในงานนี้คือ **การทำนายราคารถยนต์มือสอง** เพราะเป็นเรื่องที่เข้าใจง่าย เห็นภาพได้ชัดเจนว่าปัจจัยต่างๆ ของรถ (อายุรถ เลขไมล์ ขนาดเครื่องยนต์) ส่งผลต่อราคาอย่างไร และยังเหมาะกับการเปรียบเทียบระหว่าง Simple กับ Multiple Linear Regression ด้วย

## 2. Dataset ที่ใช้

เนื่องจากไม่ได้ใช้ dataset จากแหล่งข้อมูลสาธารณะ จึงสร้างชุดข้อมูลจำลอง (synthetic dataset) ขึ้นมาเองด้วย Python โดยกำหนดความสัมพันธ์เชิงเส้นระหว่างตัวแปรต่างๆ กับราคารถ แล้วเติม noise แบบสุ่มเข้าไป เพื่อให้ข้อมูลมีลักษณะใกล้เคียงกับข้อมูลจริงที่มีความคลาดเคลื่อนตามธรรมชาติ

ชุดข้อมูลมีทั้งหมด **200 แถว** ประกอบด้วยคอลัมน์ดังนี้:

| คอลัมน์ | ความหมาย | หน่วย |
|---|---|---|
| CarAge | อายุของรถ | ปี (0–14 ปี) |
| Mileage_km | เลขไมล์สะสม | กิโลเมตร |
| EngineSize_L | ขนาดเครื่องยนต์ | ลิตร |
| Price | ราคารถ (ตัวแปรที่ต้องการทำนาย) | บาท |

แนวคิดของข้อมูล คือ รถที่อายุมากขึ้นและวิ่งมาไกลขึ้นจะมีราคาลดลง ในขณะที่รถเครื่องยนต์ใหญ่ขึ้นจะมีราคาสูงขึ้น ซึ่งสอดคล้องกับสถานการณ์จริงในตลาดรถมือสอง

---

## 3. ขั้นตอนการทำงาน

### 3.1 เตรียมข้อมูล
โหลดข้อมูลจากไฟล์ CSV เข้ามาด้วย pandas แล้วดูภาพรวมของข้อมูลเบื้องต้น (head, describe) และดูค่า correlation ระหว่างแต่ละตัวแปรกับราคา เพื่อให้เข้าใจว่าตัวแปรใดมีความสัมพันธ์กับราคามากน้อยแค่ไหนก่อนสร้างโมเดล

### 3.2 Simple Linear Regression
ใช้ตัวแปรต้น (X) เพียงตัวเดียวคือ **อายุรถ (CarAge)** เพื่อทำนายราคา (Price) แบ่งข้อมูลเป็น Training set 80% และ Testing set 20% แล้วฝึกโมเดลด้วย `LinearRegression()` จากไลบรารี scikit-learn

โมเดลที่ได้:
```
Price = 1,663,103.91 + (-94,148.46) × CarAge
```

ผลการประเมิน:
- RMSE = 205,720.24 บาท
- R² = 0.7048

ผลลัพธ์บอกได้ว่าอายุรถเพียงตัวเดียวสามารถอธิบายความผันแปรของราคาได้ประมาณ 70% ซึ่งถือว่าพอใช้ได้ แต่ยังมีความคลาดเคลื่อนอยู่พอสมควร เพราะราคารถในความเป็นจริงไม่ได้ขึ้นอยู่กับอายุรถเพียงอย่างเดียว

### 3.3 Multiple Linear Regression
เพิ่มตัวแปรต้นเป็น 3 ตัว คือ **อายุรถ, เลขไมล์สะสม และขนาดเครื่องยนต์** เพื่อทำนายราคา โดยใช้กระบวนการเดียวกันกับ Simple Regression (แบ่ง train/test แบบเดียวกัน เพื่อให้เปรียบเทียบผลกันได้อย่างยุติธรรม)

โมเดลที่ได้:
```
Price = 1,168,274.93 + (-60,217.67 × CarAge) + (-3.11 × Mileage_km) + (273,486.64 × EngineSize_L)
```

ผลการประเมิน:
- RMSE = 68,137.31 บาท
- R² = 0.9676

---

## 4. เปรียบเทียบผลลัพธ์ระหว่างสองโมเดล

| โมเดล | ตัวแปรที่ใช้ | R² | RMSE (บาท) |
|---|---|---|---|
| Simple Linear Regression | CarAge | 0.7048 | 205,720.24 |
| Multiple Linear Regression | CarAge, Mileage_km, EngineSize_L | 0.9676 | 68,137.31 |

จะเห็นได้ชัดว่า Multiple Linear Regression ให้ผลแม่นยำกว่า Simple Linear Regression มาก ค่า R² เพิ่มขึ้นจาก 0.70 เป็น 0.97 และค่า RMSE ลดลงจากประมาณ 2 แสนบาท เหลือประมาณ 6.8 หมื่นบาท

เหตุผลที่เป็นเช่นนี้คือ ราคารถในความเป็นจริงถูกกำหนดโดยหลายปัจจัยพร้อมกัน ไม่ใช่แค่อายุรถอย่างเดียว การมีเพียงตัวแปรเดียวจึงทำให้โมเดลมองไม่เห็นภาพรวมทั้งหมด และมีความคลาดเคลื่อนสูงกว่า เมื่อเพิ่มเลขไมล์และขนาดเครื่องยนต์เข้าไป โมเดลจึงสามารถอธิบายความผันแปรของราคาได้ครอบคลุมมากขึ้น

จากค่าสัมประสิทธิ์ (coefficient) ของ Multiple Regression ยังพบว่า:
- อายุรถที่เพิ่มขึ้น 1 ปี ทำให้ราคาลดลงเฉลี่ยประมาณ 60,217 บาท
- เลขไมล์ที่เพิ่มขึ้นทุก 1 กม. ทำให้ราคาลดลงเฉลี่ย 3.11 บาท
- ขนาดเครื่องยนต์ที่เพิ่มขึ้น 1 ลิตร ทำให้ราคาเพิ่มขึ้นเฉลี่ยประมาณ 273,486 บาท

ซึ่งทั้งหมดนี้สอดคล้องกับความเข้าใจทั่วไปเรื่องตลาดรถมือสอง

จากการทำ LAB นี้ ทำให้เข้าใจมากขึ้นว่า Linear Regression เป็นเทคนิคที่ใช้ทำนายค่าต่อเนื่อง (Continuous Value) โดยอาศัยความสัมพันธ์เชิงเส้นระหว่างตัวแปรต้นกับตัวแปรตาม และการเพิ่มจำนวนตัวแปรต้นที่มีความสัมพันธ์จริงกับผลลัพธ์ (ไม่ใช่เพิ่มมั่วๆ) จะช่วยให้โมเดลทำนายได้แม่นยำขึ้นอย่างชัดเจน ซึ่งเป็นเหตุผลว่าทำไมในทางปฏิบัติจึงมักใช้ Multiple Linear Regression มากกว่า Simple Linear Regression เมื่อมีข้อมูลตัวแปรต้นให้เลือกใช้หลายตัว
